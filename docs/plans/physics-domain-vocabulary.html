The vocabulary names only physics

Lead ruling, 2026-11-23: a physics domain names an area of physics, judged from the quantity a name describes, and is never named from a data-dictionary path or data structure. The ruling came from imas-codex, where 1,042 live names carried transport because they were inherited from the IDS they came from. Read by their physics, they are 587 transport quantities and 310 quantities of the plasma's state, with the rest spread over fast particles, runaway electrons, equilibrium, current drive, MHD and auxiliary heating. The proposal for five data-structure domains was rejected. The vocabulary changes in five ways, all ruled the same day:

  • core_plasma_physics is renamed plasma_state. Its description covers the state of the plasma wherever it applies: densities, temperatures, pressures, velocities, current densities, fields, energies, composition, and global and local parameters. Many of these quantities are neutral or edge quantities with no core locus. The boundary with the edge domains is read from the name. If a quantity's name states a scrape-off-layer, divertor or wall locus, the quantity belongs to edge_plasma_physics, divertor_physics or plasma_wall_interactions. Otherwise, a state quantity belongs to plasma_state.
  • transport's description covers how particles, energy and momentum move: fluxes, transport coefficients, convection velocities, flux limiters, damping rates, confinement times, neoclassical currents, and the source and exchange terms of the particle, energy and momentum balance. A source whose name states its origin belongs to that origin's domain.
  • plasma_measurement_diagnostics is retired. It carries no name and no path.
  • computational_workflow is merged into data_management, whose description covers both. Neither carries a live standard name.
  • No domain carries an IDS list, because a domain is judged from the quantity and not from where it is stored.

Done when:

  • The vocabulary file and the generated domain enumeration carry the same 30 values, read in one run. plasma_state is among them. core_plasma_physics, plasma_measurement_diagnostics and computational_workflow are not.
  • The descriptions of plasma_state, transport and data_management state the scopes above.
  • No domain entry carries an IDS list.
  • Validation accepts plasma_state and refuses each of the three removed values by name.
  • No file in the package names a removed value, and that includes the standard-name examples resource.
  • The vocabulary contract test pins the new set. Restoring core_plasma_physics in a copy of the vocabulary makes that test fail. The log of that run is committed at docs/evidence/fragments/physics-domain-vocabulary/negative-control.log.
  • The whole test suite adds no failure at head against base.

A release candidate carries the vocabulary

imas-codex validates every stored domain against this vocabulary, and its catalog export groups names by domain. It needs a tagged release, not only the editable checkout.

Done when:

  • A release candidate newer than v0.12.0rc1 is tagged through the repository's release recipe, from the head that carries §1.
  • Its release notes name the rename, the retirement, the merge and the removal of the IDS lists.
  • An install of the tagged candidate into a clean environment reports the 30 values of §1. Its output is committed at docs/evidence/fragments/physics-domain-vocabulary/clean-install.log.
